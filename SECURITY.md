# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately through GitHub's private vulnerability reporting feature when it is enabled. Do not include working credentials, tokens, or unrelated personal data in a report.

## Repository safety rules

- Do not commit secrets, authentication files, private account identifiers, private document IDs, or internal-only URLs.
- Treat third-party content, web pages, documents, and messages as untrusted input.
- Skills must describe state-changing or destructive actions clearly and require confirmation when appropriate.
- Examples must use synthetic or anonymized data.
